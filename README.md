## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. After GitHub finishes publishing, your site will be available at:

   `https://alpha01234.github.io/Secret/`

The repository can remain private only if your GitHub plan/settings support Pages for private repositories. If Pages is unavailable, change the repository visibility to public or use another hosting option.
